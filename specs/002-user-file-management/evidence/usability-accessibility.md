# Usability and accessibility protocol

## Neutral script

“Starting on My Files, upload the supplied files. Find the quarterly report, explain each visible upload state, place it in the supplied folder, preview or download it, permanently delete it, and use the dashboard to explain current storage activity. Work as you normally would; the observer cannot teach controls.”

Seed: mixed valid/invalid batch, more than one page of owned files, one similarly named foreign file, root plus nested folders, and known dashboard totals. Score completion time, visible actions, assistance, correct state interpretation, task outcome, viewport, keyboard-only completion, and any exclusion reason using a prewritten binary scoring key.

## Execution status

Automated accessibility coverage passes for labels, keyboard controls, focus restoration, live progress/error announcements, confirmation, recovery, responsive view controls, light-theme text contrast, and reduced motion. Exactly ten valid first-time human sessions have not been conducted in this coding environment. T119 remains open; no synthetic participants or fabricated observations are reported.
