# Usability and accessibility evidence

Automated component checks cover labeled one-time-code entry, busy state semantics, alert/status announcements, anonymous/loading/forbidden administrator states, and logout/restoration cleanup. CSS provides visible focus, responsive layouts, reduced-motion overrides, and a complete light palette.

Live Chromium inspection covered keyboard-addressable labeled forms, responsive route layouts, visible loading/validation/success/anonymous/forbidden states, and reduced-motion CSS. The light palette uses high-contrast ink-on-paper surfaces and visible focus outlines. Playwright passed the same journeys at both configured origin arrangements. Participant comprehension percentages remain a product-research metric rather than an automated claim.
